# Find the issue myself

<v-click>

**Give Claude 2-3 chances, then investigate yourself**

</v-click>

<v-click>

- Coding agents can get stuck in debugging loops
- When Claude can't find root cause, step in
- Use breakpoints, logs, and human intuition
- Once you know the issue, relay it back to Claude

</v-click>
