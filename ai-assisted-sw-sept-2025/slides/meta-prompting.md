# Meta-Prompting: AI Helping AI

## The Technique
- Ask AI to improve your initial prompt before executing the task
- AI surfaces edge cases, tradeoffs, and considerations you might miss
- Use the enhanced prompt for better results

## The Process
1. Start with your simple task description
2. Ask: "Help me create a better prompt for this task"
3. AI returns refined prompt with considerations
4. Execute with the improved prompt
