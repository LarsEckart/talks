# Self-Hosted AI Safety Platform

::left::

## Setup Components
- **Open WebUI** - Self-hosted interface
- **OpenRouter.ai** - API access layer
- **Custom Safety Prompts** - Child-specific guardrails

## Key Safety Features
- No sexual/adult content
- Profanity filtering
- Violence restrictions
- Age-appropriate responses only

::right::

## Benefits Over Commercial Solutions
- **Full Control** - Customize interaction parameters
- **Cost Effective** - Alternative to subscriptions
- **Transparency** - Monitor all interactions
- **Personalization** - Custom AI personas (e.g., "Bamboo" the Panda)

# Implementation Considerations

## Parental Oversight Required
- Ongoing monitoring of interactions
- Regular review of conversation logs
- Adjustment of safety parameters as child grows

## Learning Opportunities
- Early technological literacy development
- Supervised AI interaction skills
- Understanding of AI capabilities and limitations

## Technical Benefits
- Multi-model support for different use cases
- Per-user system prompt configuration
- Complete data privacy and control
