# Coding With GPT-5: Best Practices

## Repo-Aware Editing

- Read before write: scan files, configs, deps, scripts
- Match codebase style: naming, patterns, directory structure
- Make minimal, focused diffs; avoid touching unrelated code
- Include tests where applicable; run/verify locally
